# Тысяча — Telegram-бот и веб-стол

Карточная игра **«Тысяча»**: столы на троих или четверых в Telegram, торги за прикуп, взятки, марьяжи, бочка на 880 и победа от 1000 очков.

Правила сверены с открытыми сводами ([Кубиковед](https://kubikoved.ru/pravila/tysyacha/), [IgraFan](https://thousand.igrafan.ru/help/thousand.html?lang=ru), [cards-1000](https://cards-1000.ru/pravila-igry/3-etap-torgovli)).

## Что внутри

- **Движок** с фазами: раздача → торговля → снос → заказ → розыгрыш → запись
- **Telegram-бот** на [grammy](https://grammy.dev): закрытые комнаты по ссылке и личный стол с кнопками у каждого игрока.
- **Одиночная игра** против двух ботов в Telegram или в браузере.
- **Веб-стол** с анимацией карт.

## Быстрый старт

```bash
cd tysyacha
npm install
npm test
npm run web          # красивый стол в браузере → http://127.0.0.1:8787
```

### Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Задайте переменную окружения `TELEGRAM_BOT_TOKEN` (в Cursor — через Secrets).
3. Опционально `WEB_URL` — публичный URL веб-стола для кнопки в сообщениях.
4. Запуск:

```bash
TELEGRAM_BOT_TOKEN=… npm start
```

Откройте `/start` в личном чате, выберите стол на троих или четверых и отправьте приглашение друзьям. Когда все займут места, создатель нажимает «Начать партию». У каждого игрока в личном чате обновляется изображение стола с его картами, прикупом и взяткой. Под изображением видны общий счёт, очки за сдачу и кнопки хода. `/table` присылает свежий стол, `/leave` открывает выход из комнаты, `/rules` показывает правила. `/new` запускает одиночную игру.

Комнаты хранятся в памяти процесса и сбрасываются при перезапуске. Без токена доступно веб-демо с ботами.

## Правила (кратко)

| Элемент | Как у нас |
| --- | --- |
| Колода | 24 карты: 9–Т, очки 0/2/3/4/10/11, старшинство Т&gt;10&gt;К&gt;Д&gt;В&gt;9 |
| Торговля | От 100, шаг 5; без марьяжа ≤120 |
| Прикуп | 3 карты победителю, снос по одной двум соперникам. После торгов виден победитель, карты открыты всем до первого хода |
| Вчетвером | Трое разыгрывают сдачу. Сдающий пропускает торги и розыгрыш, получает округлённые очки карт прикупа и стоимость марьяжа в прикупе. Сдающий меняется по кругу |
| Марьяж | ♠40 ♣60 ♦80 ♥100; после своей взятки, заход К/Д. В Telegram объявляется автоматически при ходе картой пары |
| Запись | Играющий: ±заказ; остальные: округление до 5. Общий счёт может быть отрицательным |
| Бочка | 880, 3 попытки, выход заказом ≥120 |
| Победа | ≥1000 после выхода с бочки |

Тузовый марьяж, золотой круг и роспись в этой версии отключены.
