# Тысяча — Telegram-бот и веб-стол

Карточная игра **«Тысяча»** для троих: торговля за прикуп, взятки, марьяжи, бочка на 880 и победа от 1000 очков.

Правила сверены с открытыми сводами ([Кубиковед](https://kubikoved.ru/pravila/tysyacha/), [IgraFan](https://thousand.igrafan.ru/help/thousand.html?lang=ru), [cards-1000](https://cards-1000.ru/pravila-igry/3-etap-torgovli)).

## Что внутри

- **Движок** с фазами: раздача → торговля → снос → заказ → розыгрыш → запись
- **ИИ-соперники** (игра один на один с двумя ботами)
- **Веб-визуализация** сукна с анимацией карт (удобно как Telegram Mini App)
- **Telegram-бот** на [grammy](https://grammy.dev): инлайн-кнопки, SVG-стол, команды

## Быстрый старт

```bash
cd tysyacha
npm install
npm test
npm run web          # красивый стол в браузере → http://127.0.0.1:8787
```

### Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Задайте переменную окружения `TELEGRAM_BOT_TOKEN` (в Cursor — через Secrets).
3. Опционально `WEB_URL` — публичный URL веб-стола для кнопки в сообщениях.
4. Запуск:

```bash
TELEGRAM_BOT_TOKEN=… npm start
```

Команды бота: `/start`, `/new`, `/table`, `/rules`, `/stop`.

Без токена поднимается только веб-демо — можно сразу играть в браузере.

## Правила (кратко)

| Элемент | Как у нас |
| --- | --- |
| Колода | 24 карты: 9–Т, очки 0/2/3/4/10/11, старшинство Т&gt;10&gt;К&gt;Д&gt;В&gt;9 |
| Торговля | От 100, шаг 5; без марьяжа ≤120 |
| Прикуп | 3 карты победителю, снос по одной двум соперникам |
| Марьяж | ♠40 ♣60 ♦80 ♥100; после своей взятки, заход К/Д |
| Запись | Играющий: ±заказ; остальные: округление до 5 |
| Бочка | 880, 3 попытки, выход заказом ≥120 |
| Победа | ≥1000 после выхода с бочки |

Тузовый марьяж, золотой круг и роспись в этой версии отключены.
